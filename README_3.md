# 칼로리 관리 시스템

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | **입력 화면** (더블클릭하면 브라우저에서 열림) |
| `profile.json` | 신체정보·목표 칼로리·탄단지 기준 (모든 계산의 원천) |
| `foods_standard.csv` | 표준 1인분 사전 (46개 항목) |
| `log_YYYY-MM.csv` | 월별 식사 기록 |
| `verify.py` | 검수 스크립트 |

## 기준값

| 항목 | 값 |
|---|---|
| 신체정보 | 여성 / 35세 / 170cm / 55kg (BMI 19.0) |
| BMR (Mifflin-St Jeor) | 1,277 kcal |
| 활동계수 | 1.55 (평균 고정, 입력 없음) |
| **목표 칼로리** | **1,980 kcal (체중 유지)** |
| 탄수화물 | 248 g |
| 단백질 | 99 g |
| 지방 | 66 g |
| 적정 판정 밴드 | 목표 ±10% (1,782 ~ 2,178 kcal) |

## 입력 화면 (index.html)

`index.html`을 더블클릭하면 브라우저에서 열립니다.

| 기능 | 설명 |
|---|---|
| 사진 자동인식 | API 키 등록 시 사진 속 음식을 자동으로 인식해 담아줍니다 |
| 다중선택 | 한 끼에 여러 음식(김치찌개 + 밥)을 담아 합산 기록 |
| 수량 조절 | −/+ 버튼, 기본 1, 0.5 단위 |
| 끼니 자동 선택 | 현재 시각 기준 자동 (칩으로 수정 가능) |
| 누적 표시 | 목표 대비 칼로리 + 탄단지 진행바 |
| CSV 내려받기 | 그날 기록을 CSV로 저장 → log 파일에 붙여넣기 |

### 끼니 자동 선택 기준

| 시간대 | 끼니 |
|---|---|
| ~09:59 | 아침 |
| 11:00~14:59 | 점심 |
| 17:00~19:59 | 저녁 |
| 그 외 (10~11시, 15~17시, 20시 이후) | 간식 |

### 사진 자동인식 설정

헤더의 **사진 자동인식 설정**에서 Anthropic API 키를 등록하면, 사진을 올릴 때
음식이 자동으로 인식되어 담깁니다. 키를 비워두면 사진을 올린 뒤 직접 고르는 방식으로 동작합니다.

- 키는 이 브라우저(localStorage)에만 저장됩니다.
- 사용 모델은 Claude Haiku 4.5이며, 호출 비용은 사용자 API 계정에 청구됩니다.
- `file://`로 열었을 때 브라우저가 요청을 막으면, 폴더에서 아래를 실행한 뒤
  `http://localhost:8000`으로 접속하세요.

```bash
cd ~/Desktop/CalorieTracker && python3 -m http.server 8000
```

기록은 브라우저에 그날 단위로 저장됩니다. 영구 보관하려면 CSV를 내려받아
`log_YYYY-MM.csv`에 붙여넣은 뒤 `verify.py`로 검수하세요.

## 매일 사용법 (대화)

사진이나 텍스트를 대화에 올리면 아래 6단계가 돌아갑니다.

| 단계 | 내용 |
|---|---|
| 1. 입력 | 사진 또는 "점심에 김치찌개, 공기밥" |
| 2. 식별 | 음식 종류 판별 → `foods_standard.csv` 우선 조회 |
| 3. 추정 | 표준 1인분 기준으로 kcal·탄단지 산출 (범위 ±15%, 신뢰도 상/중/하 표기) |
| 4. 기록 | `log_YYYY-MM.csv`에 한 줄 추가 |
| 5. 출력 | 누적 vs 목표 비교 + 남은 칼로리 + 부족 영양소 조언 |
| 6. **검수** | `verify.py` 실행 → 계산 오차 확인 후 결과 보고 |

## 6단계 검수 항목

| 항목 | 판정 |
|---|---|
| 누적 합계 오차 | CSV를 독립 재합산하여 대조 |
| 탄단지 ↔ kcal 정합성 | (탄×4 + 단×4 + 지×9) vs 기록 kcal, ±10% 초과 시 **오류** |
| 중복 입력 | 같은 날·끼니·음식 반복 시 경고 |
| 끼니 누락 | 아침/점심/저녁 중 빈 끼니 표시 |
| 표준량 일치 | 표준 1인분의 정수배가 아닌 애매한 분량 경고 |
| 목표 대비 판정 | 부족 / 적정 / 초과 |

오류가 있으면 영양 조언보다 **먼저** 보고합니다.

## 직접 실행

```bash
cd ~/Desktop/CalorieTracker

python3 verify.py              # 오늘 검수
python3 verify.py 2026-08-25   # 특정 날짜 검수
python3 verify.py --month      # 이번 달 일별 추이
```

## 기준 변경

대화로 말하면 `profile.json`을 수정합니다.

- "체중 56으로 바꿔줘"
- "목표를 감량으로 바꿔줘"
- "단백질 목표를 110g으로 올려줘"

## 표준 1인분 예시

| 음식 | 1인분 | kcal |
|---|---|---|
| 밥 | 210g (1공기) | 300 |
| 김치찌개 | 300g (1대접) | 240 |
| 삼겹살 | 150g (1인분) | 500 |
| 라면 | 120g (1봉) | 500 |
| 계란(삶은) | 50g (1개) | 75 |
| 닭가슴살 | 100g (1조각) | 110 |

전체 목록은 `foods_standard.csv` 참조.

## 알아둘 점

- 사진 기반 추정은 **오차가 큽니다.** 조리유·양념·실제 그릇 크기가 사진에 드러나지 않습니다. 신뢰도 표기(상/중/하)를 참고하세요.
- `foods_standard.csv` 값은 통상적인 기준을 반영한 **추정치**입니다. 실제 조리법에 따라 달라집니다.
- 이 시스템은 일반적인 영양 균형 참고용입니다. 질환·약물 관련 식단은 전문가와 상의하세요.
